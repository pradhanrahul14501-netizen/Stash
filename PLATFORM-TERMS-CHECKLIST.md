# Browser media capture: terms and copyright review

Capture remains user-initiated. Stash does not defeat DRM, bypass login/access controls, evade rate limits, or capture protected playback. A site may block capture or return incomplete media; Stash should show that failure instead of attempting another protected route.

Before distributing a beta that supports media from a platform, review that platform's current Terms of Service, copyright rules, API terms, and applicable local law. This is a review checklist, not legal advice or a claim that capture is allowed.

- Instagram and Facebook / Meta: review Meta's Terms, automated data collection rules, and intellectual-property terms.
- YouTube: review YouTube Terms of Service, API Services Terms, and copyright / Content ID rules.
- TikTok: review TikTok Terms, developer terms, and copyright rules.
- X: review X Terms and developer agreement/policy.
- Reddit: review Reddit User Agreement, Data API Terms, and content licensing terms.
- Pinterest: review Pinterest Terms and developer/API terms.
- Vimeo: review Vimeo Terms, API terms, and video owner download settings.
- Any other source: review its current site terms and the creator's rights before using saved media outside personal access.
