# Stash for DaVinci Resolve

The script imports every non-hidden file in `~/copy-maker/storage/integrations/davinci` into the currently open Resolve project.

## Install

1. Download `CopyMakerImport.py` from Stash Settings.
2. Copy it to `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/`.
3. Restart DaVinci Resolve.
4. Download selected Stash cloud files, place the media in the Stash DaVinci import folder, then run **Workspace → Scripts → Utility → CopyMakerImport**.

The script only imports files after you run it from Resolve. It does not upload, edit, or delete files.
