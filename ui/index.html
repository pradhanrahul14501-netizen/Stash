Network protection

                        
Checking network protection…

                    

                

                
Phone and laptop access uses HTTP on your local Wi-Fi, so use a trusted private network. Stash blocks direct public-internet connections. To enable remote access, put it behind an HTTPS reverse proxy and list that proxy’s IP in COPY_MAKER_TRUSTED_PROXY_IPS.

            


            

                

                    

                        
Encrypted backup and recovery

                        
Create a password-protected backup of your library, saved files, and account settings. Backups can be up to 50 GB.

                    

                

                
                
                
                
                

                    
                

                
                
                
                
                

                    
                

                
Use at least 12 characters and keep the password somewhere separate. Stash cannot recover it.

                
Create and restore backups from Stash on this Mac at http://127.0.0.1:5050; the password is not sent over Wi-Fi. A restore replaces the current Stash library on the next restart and signs all devices out.
